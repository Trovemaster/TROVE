# C2H6 (Ethane), SPAR kinetic energy operator and G36(EM) symmetry

Full-dimensional (18D) C2H6 in the `R-R16-BETA16-THETA-TAU-11` coordinates
(`TRANSFORM`), `G36(EM)` extended molecular symmetry group, non-rigid reference
configuration along the torsion (`REFER-CONF non-RIGID`). The basis set is small and
meant for testing: one quantum (`range 0,1`) in each of the modes 1–17 and a Fourier
basis for the torsion, mode 18 (`range 0,11`, 360 points, $\tau \in [0^\circ, 720^\circ]$,
`periodic 1`). The exact kinetic energy operator is read in SPAR (sum-of-products)
form from `kinetic.chk` (`BASIC-FUNCTION mass`, `kinetic read with_modes`) and
`combination.chk`, generated by `A2B6.nb` (Yurchenko et al., J. Chem. Phys.,
https://doi.org/10.1063/5.0339739). The potential energy function
(`POTEN_C2H6_88_COS3TAU_G36`) is expanded by TROVE in step 1 ($J=0$) and saved
in `potential.chk`, which the $J>0$ steps read.

This folder also includes the $G_{36}(\text{EM})$ PES fitting programs
(`C2H6_G36_v8.f90` and `C2H6_G36_v12.f90`) and associated ab initio fitting
inputs and outputs (`C2H6_2D-pot4_July2021_v8_32.inp`, `C2H6_3D_v8_46.inp`,
`C2H6_3D_v8_46.res`), as well as earlier non-SPAR TROVE inputs.

## Files

| File | Purpose |
| :--- | :--- |
| `C2H6_SPAR_G36_J0.inp` | Step 1, $J = 0$: potential expansion, primitive and contracted basis sets, vibrational matrix elements (`matelem save split`) and $J = 0$ energies. |
| `C2H6_SPAR_G36_J1.inp` .. `C2H6_SPAR_G36_J4.inp` | Steps 2–5, $J = 1, 2, 3, 4$: read the checkpoints of step 1 (`matelem read split`) and compute rovibrational energies for $J = 1..4$. |
| `C2H6_SPAR_G36_J1.out` .. `C2H6_SPAR_G36_J4.out` | Reference outputs for $J = 1, 2, 3, 4$. |
| `kinetic.chk`, `combination.chk` | Exact SPAR KEO and basis-combination table generated by `A2B6.nb`. |
| `A2B6.nb` | Mathematica notebook deriving the exact SPAR KEO for $\text{A}_2\text{B}_6$ ($\text{C}_2\text{H}_6$). |
| `C2H6_G36_v8.f90`, `C2H6_G36_v12.f90` | Standalone Fortran PES fitting programs for $\text{C}_2\text{H}_6$ in $G_{36}(\text{EM})$ symmetry (`v8`: $\cos 3\bar{\tau}$; `v12`: $\cos 3\bar{\tau}$ and $\sin 3\bar{\tau}$). |
| `C2H6_2D-pot4_July2021_v8_32.inp`, `C2H6_3D_v8_46.inp`, `C2H6_3D_v8_46.res` | Ab initio PES fitting input files and fitted output (`C2H6_3D_v8_46.res`). |
| `C2H6_tau*.inp` | Earlier TROVE inputs for $\text{C}_2\text{H}_6$ with the same coordinates, symmetry group and potential, but with the TROVE-expanded (non-SPAR) KEO and larger basis sets. |
| `run.sh` | Runs the SPAR $G_{36}(\text{EM})$ workflow for $J = 0..4$. |

## Running

Copy the folder to a working directory and run the steps in the order listed
above (or `./run.sh`; set `TROVE_EXE` to the TROVE executable, otherwise `j-trove.x`
is taken from the repository root or `PATH`):

```bash
cp -r inputs/C2H6 /path/to/work && cd /path/to/work/C2H6
./run.sh
```

Step 1 ($J = 0$) takes about 3.5 min on 8 cores; each $J > 0$ step takes about 30 s.
