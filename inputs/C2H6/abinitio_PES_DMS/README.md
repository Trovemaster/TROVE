# C2H6 (Ethane): ab initio PES and DMS in the SPAR format, J = 0 energies and vibrational intensities

This example uses the same coordinates (`R-R16-BETA16-THETA-TAU-11`), the same $G_{36}(\text{EM})$
symmetry group and the same exact SPAR kinetic energy operator as the example in the parent folder
(`../`), but all three operators are read from checkpoint files in the SPAR (`with_modes`) format:

```
CHECK_POINT
kinetic     read with_modes     <- kinetic.chk
potential   read with_modes     <- potential.chk
external    read with_modes     <- external.chk
```

Step 1 computes the $J = 0$ energies and saves the basis set, the eigenvectors and the vibrational
and dipole matrix elements; step 2 computes the $J = 0$ vibrational transition moments (`TM`) and
writes them as ExoMol `.states` and `.trans` files.

## Files

| File | Purpose |
| :--- | :--- |
| `kinetic.chk` | Exact SPAR KEO of $\text{C}_2\text{H}_6$, identical to `../kinetic.chk` (generated by `../A2B6.nb`). |
| `potential.chk` | *Ab initio* PES: 531-parameter $G_{36}(\text{EM})$-invariant fit to 43,738 frozen-core CCSD(T) energies on 1D–6D grids, extrapolated to the complete basis set limit from aug-cc-pVTZ and aug-cc-pVQZ (CBS(T,Q)). RMS deviations: 1.00, 1.50 and 1.67 cm-1 for energies below 2,000, 10,000 and 25,000 cm-1. Expanded to 4th order (`PotOrder 4`, 8,258 terms). |
| `external.chk` | *Ab initio* DMS: 179-parameter $G_{36}(\text{EM})$ symmetry-adapted fit to 19,289 orbital-relaxed CCSD(T)/aug-cc-pVTZ dipole moments on 1D–4D grids (RMS deviation 0.39 mD), expanded to 4th order (`ORDER 4`). |
| `C2H6_CBS-TQ_6D_P2_step1_J0.inp` | Step 1 with the small test basis $P = 2$ (`Npolyads 17`): primitive and contracted basis sets, $J = 0$ energies and eigenvectors, vibrational and dipole matrix elements (`matelem save split`, `extmatelem save split`). |
| `C2H6_CBS-TQ_6D_P2_step2_TM.inp` | Step 2: $J = 0$ transition moments from the four states of the ground torsional quartet (lower-state energies below 10 cm-1) to all states below 10,000 cm-1, written as `C2H6_CBS_TQ_6D_P2_0_0.states` and `C2H6_CBS_TQ_6D_P2_0_0.trans` (`EXOMOL`, 296 K, nuclear-spin statistical weights set to 1). |
| `C2H6_CBS-TQ_6D_P2_step1_J0.out`, `C2H6_CBS-TQ_6D_P2_step2_TM.out`, `C2H6_CBS_TQ_6D_P2_0_0.states`, `C2H6_CBS_TQ_6D_P2_0_0.trans` | Reference outputs of steps 1 and 2. |
| `C2H6_CBS-TQ_6D_P4_step1_J0.inp`, `C2H6_CBS-TQ_6D_P4_step2_TM_hot.inp` | The same two steps with the larger basis $P = 4$ (`Npolyads 29`) used for production calculations; step 2 computes the hot-band transitions from all states below 4,000 cm-1 to states below 12,000 cm-1. |
| `run.sh` | Runs steps 1 and 2 with $P = 2$. |

## Notes on the inputs

* `POTEN` (the analytic model `POTEN_C2H6_88_COS3TAU_G36`) and `EXTERNAL` (with dummy parameters)
  are kept for the input parser. The potential and dipole expansions used in the calculations are
  read from `potential.chk` and `external.chk`.
* The Morse parameters of the stretching coordinates in `SPECPARAM` (`amorseCC 1.456`,
  `amorseCH 2.058`) define the coordinates of the PES and DMS expansions and must not be changed.
* The `BASIC-FUNCTION` block describes the torsion (mode 18) with 15 functions: functions 1–5 are
  used by the KEO and functions 6–15 ($\cos kq_{18}$, $\sin kq_{18}$, $k = 1, 1.5, 2, 2.5, 3$) by the
  DMS expansion in `external.chk`. Do not use these checkpoints with the 5-function block of
  `../C2H6_SPAR_G36_J0.inp`.
* The basis set is controlled by the polyad number $P$: `Npolyads` $= 6P + 5$ in `PRIMITIVES` and
  `CONTRACTION`, `range 0,P` for modes 1–17 and `range 0,6P+5` for the torsion (mode 18).
* For $P \ge 5$, increase the number of torsional grid points (`points 360` on the mode 18 `fourier`
  line, e.g. to `points 3600`): with 360 points the torsional Fourier quadrature is no longer exact
  and the ground torsional quartet is split artificially.
* `ZPE` in step 2 is the $J = 0$ zero-point energy of step 1 (16251.750221 cm-1 for $P = 2$). If
  `ZPE` is not given, the lowest $J = 0$ energy of $A_{1s}$ symmetry is used.
* If `.states` or `.trans` files of the same name already exist, TROVE writes the new ones with a
  time-stamp suffix.

## Running

Copy the folder to a working directory and run the two steps in order (or `./run.sh`; set
`TROVE_EXE` to the TROVE executable, otherwise `j-trove.x` is taken from the repository root or
`PATH`):

```bash
cp -r inputs/C2H6/abinitio_PES_DMS /path/to/work && cd /path/to/work/abinitio_PES_DMS
./run.sh
```

| Basis | Contracted functions | $J = 0$ states | Step 1 | Step 2 | Dipole matrix elements (`extmatelem1..3.chk`) |
| :--- | ---: | ---: | :--- | :--- | :--- |
| $P = 2$ | 1,140 | 508 | 2 min on 8 cores, 0.3 GB of RAM | 2 s | 3 × 10 MB |
| $P = 4$ | 40,230 | 17,900 | 26 GB of RAM | 54 GB of RAM (hot bands) | 3 × 13 GB |

For $P = 2$, step 1 writes about 0.3 GB of checkpoint files in total.

## Reference results ($P = 2$)

$P = 2$ is a functional test only: the vibrational energies are far from converged, and
production calculations need at least $P = 4$ (see the $P = 4$ inputs). Zero-point energy
16251.750221 cm-1; lowest $J = 0$ levels in cm-1, relative to the zero-point energy:

| Symmetry | Energy | Symmetry | Energy |
| :---: | ---: | :---: | ---: |
| A1s | 0.000000 | A1d | 630.662371 |
| E3d | 0.000858 | E3s | 630.721786 |
| E3s | 0.002260 | E3d | 630.842032 |
| A3d | 0.002770 | A3s | 630.902761 |

The strongest transitions in `C2H6_CBS_TQ_6D_P2_0_0.trans` are in the C–H stretching region
(3200–3350 cm-1 with this basis), e.g. `E1d` ← `A1s` at 3334.61 cm-1 with
$A$ = 134.7 s-1.
