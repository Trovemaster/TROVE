# C2H2 6D `singular_3D` Rovibrational & Transition-Intensity Examples in TROVE

This directory contains input files, pre-computed checkpoint files, and reference output files for 6D rovibrational energy and transition-intensity calculations of acetylene ($\text{C}_2\text{H}_2$) in `TROVE` using:
- **Exact polynomial $t$-$s$ kinetic energy operator** (`TROVE_EXT_T_S`, 4th-order expansion) with the singular $1/\sin^2\rho_i$ ($i=1,2$) terms marked by trailing underscores (`_`) in `kinetic.chk`.
- **Uncontracted 3D coupled singular bend–bend–torsion basis (`singular_3D`)** on $(s_4=\rho_1, s_5=\rho_2, s_6=\tau)$ constructed from associated Legendre basis functions (`sinrho-legendre-k-sing` for modes 4 and 5) and unoptimised half-integer Fourier torsional functions (`fourier-unoptimised` for mode 6 on $\tau \in [0, 4\pi]$, `borders 0., 720.0 deg`), enforcing the exact angular-momentum constraint $\{l_1, l_2\} = \{|k_\tau - K/2|,\, k_\tau + K/2\}$ at every basis function and matrix element.
- **Extended $\mathcal{D}_{2h}(\text{M})$ molecular symmetry** on $\tau \in [0, 4\pi]$ (`SYMGROUP D2h(M)`), where physical single-valued rovibrational wavefunctions ($E'\Psi = +\Psi$) span the four irreps `gamma 1 2 3 4` ($A_g, A_u, B_{1g}, B_{1u}$), while the double-valued irreps ($B_{2g}, B_{2u}, B_{3g}, B_{3u}$) are used only at $J=0$ to generate the $K=\text{odd}$ contracted vibrational blocks ($B_{3g}$ for $\Pi_g$, $B_{2u}$ for $\Pi_u$).
- **$K$-parametrised $J=0$ contracted basis (`kmax 2`)** that builds and stores all $K \le K_{\max}$ contracted 3D and 6D basis blocks during the $J=0$ step (`contr_*.chk`, `matelem*.chk`) for subsequent $J>0$ Coriolis-coupled rovibrational diagonalizations (`J=1, 2`) and dipole transition-moment contractions (`extmatelem*.chk`).
- **Cylindrically regular 6D Potential Energy Function (`POTEN_C2H2_MORSE_COSALPHA_COSNTAU-SIN-SIN`)**:
  $$V(\mathbf{q}) = \sum_{ijklmn} c_{ijklmn} f_1^i f_2^j f_3^k f_4^l f_5^m \cos(n\tau) \times (\sin\rho_1 \sin\rho_2)^n,$$
  where $f_1 = 1 - e^{-a_1(R_{\text{CC}}-R_{\text{CC}}^{\text{eq}})}$, $f_{2,3} = 1 - e^{-a_2(r_{1,2}-r_{\text{CH}}^{\text{eq}})}$, and $f_{4,5} = 1 - \cos\rho_{1,2}$ ($n = 0, \dots, 4$). The exact factor $(\sin\rho_1\sin\rho_2)^n$ guarantees cylindrical smoothness and resolution of torsional degeneracies whenever either $\text{C}-\text{C}-\text{H}$ angle approaches linearity ($\rho_1 \to 0$ or $\rho_2 \to 0$).
- **6D Bisector-Frame Dipole Moment Surface (`external.chk`) & `singular_3D` `is_extf` Intensities**:
  Supports $\Delta K = 0$ parallel ($\mu_z$, `imu = 3`, $B_{1u}$) and $\Delta K = \pm 1$ perpendicular ($\mu_x, \mu_y$, `imu = 1, 2`, $B_{2u} / B_{3u}$ with $\cos(\tau/2) / \sin(\tau/2)$) dipole matrix elements in `singular_3D`, reproducing exact Hönl–London $\times g_{\text{ns}}$ line-strength ratios (`1 : 3` para/ortho nuclear-spin weights `GNS 1.0 1.0 3.0 3.0 0.0 0.0 0.0 0.0`).
- **PES refinement fields**: `EXTERNAL` blocks of `TYPE POTENTIAL` (scalar potential corrections used by `FITTING`) are evaluated in `singular_3D` with the same $\Delta K = 0$ rule as the PEF; dipole (vector) fields keep the $\Delta K = 0, \pm 1$ rules above.

## Files

- **Test Morse-$\cos\alpha$ PES ($P_{\max}=12$, $K \le 2$)**:
  - `C2H2_sing3D_D2h_J0_kmax2.inp` / `.out`: $J=0$ ($K \le 2$, $P_{\max}=12$) calculation on `potential.chk` ($\text{ZPE} = 5765.537473\text{ cm}^{-1}$).
  - `C2H2_sing3D_D2h_J1.inp` / `.out`: $J=1$ ($K \le 1$, `gamma 1 2 3 4`) rovibrational calculation ($2B_0 = 2.346311\text{ cm}^{-1}$, $\Delta_{fe}(\nu_4, J=1) = +0.010538\text{ cm}^{-1}$, $\Delta_{fe}(\nu_5, J=1) = +0.009184\text{ cm}^{-1}$).
  - `C2H2_sing3D_D2h_J2.inp` / `.out`: $J=2$ ($K \le 2$, `gamma 1 2 3 4`) rovibrational calculation ($6B_0 - 24D_0 = 7.038840\text{ cm}^{-1}$, $\Delta_{fe}(J=2) / \Delta_{fe}(J=1) = 3.000$, $\Delta_{g/u}$ $K=2$ levels).
- **4,331-Point `CCSD(T)/CBS(aug-cc-pVTZ, aug-cc-pVQZ)` Ab Initio PES ($P_{\max}=12$, $K \le 2$)**:
  - `C2H2_CBS_PES_poten.inp_block` & `potential_CBS.chk`: 257-parameter (`NPARAM 264`, 466 expanded terms) 6D `POTEN_C2H2_MORSE_COSALPHA_COSNTAU-SIN-SIN` fit to 4,331 `CCSD(T)/CBS` geometries ($\text{RMSD} = 0.611\text{ cm}^{-1}$ for $E \le 2,000\text{ cm}^{-1}$ and $0.943\text{ cm}^{-1}$ for $E \le 15,000\text{ cm}^{-1}$).
  - `C2H2_sing3D_D2h_CBS_PES_J0.inp` / `.out`: $J=0$ ($K \le 2$, $P_{\max}=12$) calculation ($\text{ZPE} = 5759.948073\text{ cm}^{-1}$).
  - `C2H2_sing3D_D2h_CBS_PES_J1.inp` / `.out`: $J=1$ ($K \le 1$, `gamma 1 2 3 4`) rovibrational calculation ($2B_0 = 2.346535\text{ cm}^{-1}$).
  - `C2H2_sing3D_D2h_CBS_PES_J2.inp` / `.out`: $J=2$ ($K \le 2$, `gamma 1 2 3 4`) rovibrational calculation ($6B_0 - 24D_0 = 7.039563\text{ cm}^{-1}$).
- **6D Benchmark DMS & Transition Intensities ($P_{\max}=12$, $J = 0, 1, 2$)**:
  - `external.chk`: 6D $\mathcal{D}_{\infty h}$-invariant analytical benchmark bisector-frame DMS ($\mu_x, \mu_y, \mu_z$).
  - `C2H2_sing3D_D2h_CBS_DMS_J0.inp` / `.out`: Computes contracted dipole matrix elements `extmatelem{1,2,3}.chk` in `singular_3D`.
  - `C2H2_sing3D_D2h_CBS_intens.inp` / `.out`: Computes 296 K absorption intensities (`J 0 2`) across parallel ($\Sigma_u^+ \leftarrow \Sigma_g^+$), perpendicular ($\Pi_u \leftarrow \Sigma_g^+$), and hot ($\Pi_g \to \Sigma_u^\pm, \Delta_u$) bands.
- **Converged $P_{\max}=12$ production basis, `CCSD(T)/CBS` PES ($K \le 5$, $J = 0 \dots 5$)**:
  - `C2H2_sing3D_D2h_CBS_P12_J0_kmax5.inp` / `.out`: $J=0$ step that builds all $K \le 5$ contracted blocks needed for $J \le 5$ (copy `potential_CBS.chk` to `potential.chk` first). Polyad weights `resc 2.0` for the three stretches and both bends and `resc 0.5` for the torsion (`lmax 5`), `CONTRACTION enercut 24000.0` and `DIAGONALIZER enermax 16000.0` (eigenvectors kept up to $16,000\text{ cm}^{-1}$ above the ZPE). Starts from scratch (`basis_set save`, `CONTRACT save`) and writes `matelem1..12.chk` (`matelem save split`, $12 \times 347$ MB) together with the $J=0$ eigenvectors. $\text{ZPE} = 5759.187092\text{ cm}^{-1}$; 217 s on 32 OpenMP threads with OpenBLAS.
  - `C2H2_sing3D_D2h_CBS_P12_J1.inp` / `.out` and `C2H2_sing3D_D2h_CBS_P12_J5.inp` / `.out`: $J=1$ and $J=5$ from the $J=0$ checkpoints (`matelem read split`, a few seconds each); for $J = 2, 3, 4$ set `Jrot J, kmax J`. Ground-state $E(J=1) = 2.346281\text{ cm}^{-1}$ and $E(J=5) = 35.192856\text{ cm}^{-1}$; $J=1$ $\ell$-type doubling $0.010446\text{ cm}^{-1}$ ($\nu_4$, $\Pi_g$) and $0.009343\text{ cm}^{-1}$ ($\nu_5$, $\Pi_u$).
  - Basis convergence ($J=0$, $K=0$, same weights, $P_{\max} = 12 \to 14 \to 16$): the ZPE changes by $5 \times 10^{-4}\text{ cm}^{-1}$; the median $|E(P_{\max}{=}12) - E(P_{\max}{=}16)|$ is 0.006, 0.08 and $1.9\text{ cm}^{-1}$ for states with $2(v_1+v_2+v_3)+v_4+v_5 = 2$, 4 and 6 (0.0003, 0.012 and $0.19\text{ cm}^{-1}$ for $P_{\max}=14$).
- **Empirically Refined $P_{\max}=12$ Production PES (`potential_Refined_P12.chk`, $K \le 5$, $J \in \{0 \dots 5, 10, 15, 20\}$)**:
  - `C2H2_Refined_P12_poten.inp_block` & `potential_Refined_P12.chk`: 266-parameter (`NPARAM 266`, 469 symmetrized `with_modes` terms, 106 varied wall-safe parameters) Stage 2 empirically refined 6D PES fitted to 1,082 MARVEL experimental energy levels across $J \in \{0, 1, 2, 3, 4, 5, 10, 15, 20\}$ ($K \le 5$, $E \le 8,000\text{ cm}^{-1}$) constrained by 4,331 reference geometries (`FIT_FACTOR 1.0e3`). Reduces the true re-contracted variational RMSD across all 1,082 MARVEL $J \in \{0\dots 5, 10, 15, 20\}$ levels from $5.5790\text{ cm}^{-1}$ ($J=0\dots 5$ CBS) and $0.5879\text{ cm}^{-1}$ (Stage 1) to **$0.4770\text{ cm}^{-1}$** ($\text{MAD} = 0.3352\text{ cm}^{-1}$, median $|\Delta E| = 0.2314\text{ cm}^{-1}$), and across the 727 $J=0\dots 5$ levels from $0.4288\text{ cm}^{-1}$ (Stage 1) to **$0.3536\text{ cm}^{-1}$** ($\text{MAD} = 0.2513\text{ cm}^{-1}$, median $|\Delta E| = 0.1798\text{ cm}^{-1}$).
  - `C2H2_sing3D_D2h_Refined_P12_J0_kmax5.inp` / `.out`: Full variational $J=0$ ($K \le 5$, $P_{\max}=12$) calculation from scratch (`basis_set save`, `CONTRACT save`, `matelem save split`, `EIGENFUNC save`) on `potential_Refined_P12.chk` (copy `potential_Refined_P12.chk` to `potential.chk` first). True re-contracted $\text{ZPE} = 5766.270241\text{ cm}^{-1}$.
  - `C2H2_sing3D_D2h_Refined_P12_J1.inp` / `.out`, `C2H2_sing3D_D2h_Refined_P12_J2.inp` / `.out`, `C2H2_sing3D_D2h_Refined_P12_J5.inp` / `.out`, `C2H2_sing3D_D2h_Refined_P12_J10.inp` / `.out`, `C2H2_sing3D_D2h_Refined_P12_J15.inp` / `.out`, and `C2H2_sing3D_D2h_Refined_P12_J20.inp` / `.out`: Full variational $J = 1, 2, 5, 10, 15, 20$ calculations on the Stage 2 refined PES (`matelem read split`).
- `kinetic.chk`: Pre-computed 4th-order `TROVE_EXT_T_S` kinetic energy expansion for $\text{C}_2\text{H}_2$.
- **6th-order *ab initio* `CCSD(T)/CBS(aug-cc-pVTZ, aug-cc-pVQZ)` DMS on the refined $P_{\max}=12$ basis ($K \le 5$, $J = 0 \dots 5$)**:
  - `external_CBS_6th.chk`: 784-term complete-form TROVE `external.chk` (`imu = 1, 2`: 280 terms each from 140 generators; `imu = 3`: 224 terms from 112 generators) fitted to all 19,263 non-centrosymmetric `CCSD(T)/CBS` geometries of the complete 20,000-point grid (the other 737 are centrosymmetric, where $\boldsymbol{\mu} = 0$ by symmetry). Includes all two-bend $\Delta K = \pm 1$ couplings $(1-\cos\rho_1)^d (1-\cos\rho_2)^e (\sin\rho_1\sin\rho_2)^f \cos(f\tau) \sin\rho_{1,2} (\cos(\tau/2), \pm\sin(\tau/2))$ ($f = 0, 1, 2$), supported directly by `PTsingular_3D_me6`. Fit RMSD for $E \le 10{,}000\text{ cm}^{-1}$: $\mu_x$ 0.00017 D, $\mu_y$ 0.00016 D, $\mu_z$ 0.00030 D (and for $E \le 5{,}000\text{ cm}^{-1}$: $\mu_x$ 0.00011 D, $\mu_y$ 0.00013 D, $\mu_z$ 0.00022 D). TROVE always reads `external.chk`, so copy `external_CBS_6th.chk` to `external.chk` before the DMS steps (the analytical benchmark `external.chk` stays in place for the test examples).
  - `C2H2_sing3D_D2h_Refined_P12_J3.inp` and `C2H2_sing3D_D2h_Refined_P12_J4.inp`: $J = 3, 4$ energy runs (`EIGENFUNC save`) completing the refined $J = 0 \dots 5$ set.
  - `C2H2_sing3D_D2h_Refined_P12_DMS_J0_kmax5.inp`: $J=0$ contraction of the dipole matrix elements (`external read with_modes`, `extmatelem save split`). Run it after all energy runs; it writes its primitive basis to `prim_bset_dms.chk` (`chk_file`), so the `prim_bset.chk` of the energy runs is not overwritten.
  - `C2H2_sing3D_D2h_Refined_P12_intens.inp`: 296 K absorption intensities for $J = 0 \dots 5$ ($\text{ZPE} = 5766.270241\text{ cm}^{-1}$, $\tilde\nu \le 10{,}000\text{ cm}^{-1}$, $E'' \le 6{,}000\text{ cm}^{-1}$, $E' \le 16{,}000\text{ cm}^{-1}$), reading `prim_bset_dms.chk`.
  - `RUN_P12_DMS=1 ./run.sh` runs the whole chain. A $K \le 1$, $J \le 1$ check of the same inputs gives $S = 0.09784\text{ D}^2$ for the $\nu_5$ R(0) line ($|\mu_{\text{vib}}| = 0.313\text{ D}$).
- `run.sh`: Helper script to run the full $J=0, 1, 2$ energy, DMS contraction, and intensity pipeline; `RUN_P12=1 ./run.sh` also runs the converged $P_{\max}=12$ CBS and Refined $J = 0, 1, 2, 5$ examples, and `RUN_P12_DMS=1 ./run.sh` the refined $J = 0 \dots 5$ intensities with the 6th-order `CCSD(T)/CBS` DMS.
