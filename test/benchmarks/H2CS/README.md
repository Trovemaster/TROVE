## TROVE H2CS Benchmark

This is a J=0 regression benchmark for [TROVE](https://github.com/Trovemaster/TROVE) based on the ExoMol `1H2-12C-32S` MOTY model (`Npolyads 6`), testing curvilinear kinetic coordinates (`BOND-LENGTH`, `ANGLE`, `DIHEDRAL`) read from `kinetic.chk` together with `poten_zxy2_morse_cos` and `dms_zxy2_morbid`.
